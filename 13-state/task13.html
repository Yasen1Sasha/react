Крок 1 Віджет: Лічильник кліків (Числовий стан)

Що потрібно зробити:

Створюємо перший ізольований компонент. Його мета — навчитись працювати з найпростішим числовим станом.

  1. Створи файл Counter.jsx у папці src/components/.
  2. Всередині компонента Counter оголоси стан з назвою count та початковим значенням 0.
  3. Створи функцію-обробник handleClick, яка буде викликати функцію-сетер і передавати їй поточне значення стану плюс один.
  4. У return поверни контейнер <div className="counter-container">, в якому буде тег <p> з текстом "Ви натиснули {count} разів".
  5. Додай кнопку "Збільшити лічильник" і прив'яжи до неї обробник події кліку.

💡 Підказка:

Використовуй деструктуризацію масиву для створення стану: const [назва, функціяЗміни] = useState(початковеЗначення). Подію на кнопку вішай через атрибут onClick.

Очікуваний візуальний результат:

Ви натиснули 0 разів

Крок 2 Віджет: Зміна фону (Рядковий стан та інлайн-стилі)

Що потрібно зробити:

Продовжуємо наповнювати дашборд. Тепер стан буде зберігати не число, а рядок (код кольору), і цей стан керуватиме стилями.

  1. Створи файл ColorChanger.jsx.
  2. Оголоси стан color із початковим значенням '#ffffff' (білий колір).
  3. У функції handleClick згенеруй випадковий колір і передай його в сетер стану. (Формула генерації дається у підказці).
  4. У return поверни <div className="color-changer-container">.
  5. Головне: прив'яжи стан кольору до атрибута style цього <div>, щоб динамічно змінювати backgroundColor.
  6. Додай абзац із текстом "Колір фону змінюється при натисканні." та кнопку для зміни кольору.

💡 Підказка:

Щоб згенерувати випадковий HEX-колір, збережи у змінну цей вираз:
'#' + Math.floor(Math.random() * 16777215).toString(16)

Пам'ятай, що інлайн-стилі в React пишуться як об'єкт: style={{ CSS_Властивість: значенняЗіСтану }}.

Очікуваний візуальний результат:

Колір фону змінюється при натисканні.

*Фон має змінюватися на випадковий при кожному кліці.

Крок 3 Віджет: Світлофор (Умовна логіка переходів)

Що потрібно зробити:

Ускладнюємо логіку. Тепер зміна стану залежить від його попереднього значення (циклічний перехід). А стилі будуть застосовуватись за допомогою тернарних операторів.

  1. Створи TrafficLight.jsx. Стан color за замовчуванням має бути 'red'.
  2. Напиши обробник handleClick, у якому через конструкцію if / else if / else реалізуй логіку: якщо червоний -> стає жовтим, якщо жовтий -> стає зеленим, інакше -> знову червоний.
  3. У розмітці (в контейнері traffic-light-container) створи три <div className="light">.
  4. Задай кожному "ліхтарю" інлайн-стиль: якщо поточний стан співпадає з кольором ліхтаря — він має відповідний колір, інакше він стає 'gray'.
  5. Додай кнопку "Переключити".

💡 Підказка:

Для стилізації використовуй тернарний оператор у стилях:
style={{ backgroundColor: стан === 'red' ? 'red' : 'gray' }}
Зроби так для кожного з трьох кольорів (red, yellow, green).

Крок 4 Віджет: Тернарна кнопка (Булевий стан)

Що потрібно зробити:

Віджети часто мають всього два стани (Увімкнено/Вимкнено). Реалізуємо булевий перемикач.

  1. Створи TernaryButton.jsx.
  2. Оголоси булевий стан isToggled зі значенням false.
  3. У handleClick інвертуй стан (переводь у протилежне значення при кожному кліці).
  4. Відрендери заголовок "Завдання: Тернарна кнопка".
  5. Відрендери кнопку. Текст всередині кнопки має залежати від стану: "Кнопка увімкнена" або "Кнопка вимкнена".
  6. Нижче додай абзац, у якому жирним текстом (<strong>) динамічно виводиться "Увімкнено" або "Вимкнено".

💡 Підказка:

Інвертувати стан найпростіше за допомогою логічного "НІ" (знак оклику): функціяСетер(!поточнийСтан).
Для зміни тексту використовуй фігурні дужки прямо в JSX: { умова ? 'текст 1' : 'текст 2' }

Крок 5 Віджет: Видалення зі списку (Масиви та імутабельність)

Що потрібно зробити:

Найскладніший віджет. Робота зі станом-масивом вимагає дотримання принципу незмінності (immutability).

  1. Створи DeletableList.jsx.
  2. Оголоси стан items, початкове значення — масив рядків: ['Яблуко', 'Банан', 'Виноград', 'Апельсин'].
  3. Створи функцію handleDelete, яка приймає індекс (indexToDelete).
  4. У цій функції створи новий масив за допомогою методу .filter() (відфільтруй так, щоб індекс поточного елемента не дорівнював indexToDelete). Запиши новий масив у стан.
  5. Виведи масив у вигляді маркованого списку <ul>, використовуючи метод .map().
  6. Кожен <li> повинен містити назву фрукта і кнопку "Видалити".

💡 Важливі підказки:

  • ОБОВ'ЯЗКОВО додай атрибут key={index} до тега <li>.
  • Оскільки функція видалення приймає аргумент, ти НЕ можеш написати просто onClick={handleDelete(index)} (бо вона викличеться відразу при рендері). Потрібно огорнути її в анонімну стрілкову функцію: onClick={() => handleDelete(index)}.

Фінал Збірка Дашборду (App.jsx)

Що потрібно зробити:

Ми створили всі необхідні цеглинки. Тепер зберемо їх в єдиному місці, щоб побачити, що стан кожного компонента ізольований і вони не заважають один одному.

  1. Відкрий головний файл App.jsx.
  2. Імпортуй туди всі створені компоненти: Counter, ColorChanger, TrafficLight, TernaryButton, DeletableList.
  3. У return компонента App виведи їх один за одним, огорнувши кожен у <div className="task-section"> та додавши відповідні заголовки <h2> (наприклад "Завдання 1: Лічильник кліків" тощо).
  4. Оскільки елементів кілька, не забудь огорнути весь вміст return у React-фрагмент <> ... </>.

Очікуваний фінальний результат:

У тебе повинна вийти довга сторінка, поділена на секції. Натискання на Світлофор ніяк не впливатиме на Лічильник або зміну фону. Ти успішно застосував інкапсуляцію стану в React та написав код, ідентичний еталонному матеріалу! 🎉
