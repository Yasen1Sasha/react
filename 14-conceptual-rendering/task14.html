Тема: Умовний рендеринг та робота зі списками

👋 Практичне заняття!

Ваше завдання — послідовно виконати всі кроки. Кожне наступне завдання доповнює попереднє.

Важливо: У самому низу цієї сторінки є стартовий CSS-код. Скопіюйте його у ваші файли стилів перед початком роботи, щоб не витрачати час на дизайн.

1

Налаштування Роутингу (Головна сторінка)

Мета: Створити каркас додатку з використанням react-router-dom. Це наш перший, глобальний рівень умовного рендерингу.

Кроки виконання:

  1. Створіть папку pages та порожні компоненти: HomePage, RegistrationPage, TodoListPage, та компонент ProductFilter.
  2. У HomePage створіть навігаційне меню з посиланнями (компонент Link) на майбутні 3 завдання.
  3. У головному файлі App.jsx налаштуйте Router та Routes.
  4. Пропишіть маршрути (Route) для головної сторінки ("/") та інших створених компонентів.

💡 Підказка:

Компонент Routes працює як великий switch/case. Він перевіряє поточний URL і рендерить лише той компонент, чий path співпадає. Не забудьте обгорнути все у <Router>!

2

Динамічна Реєстрація (Оператор &&)

Мета: Створити форму, поля якої з'являються поступово залежно від введених користувачем даних.

Кроки виконання:

  1. Створіть стани (state) для: імені, віку, email та окремий стан для видимості поля email (boolean).
  2. Створіть інпут для введення імені.
  3. Використайте логічне І (&&): показуйте інпут для вводу віку тільки якщо ім'я не порожнє.
  4. Напишіть функцію обробки зміни віку. Якщо введений вік >= 18, змінюйте стан видимості email на true.
  5. Використайте умовний рендеринг, щоб показати поле email тільки якщо стан видимості true.
  6. Зробіть кнопку "Зареєструватися" неактивною (атрибут disabled), якщо: немає імені, АБО немає віку, АБО (поле email видиме, але сам email не введено).

💡 Підказки:

  • Синтаксис умовного рендерингу: {умова && <МійКомпонент />}.
  • Значення з e.target.value завжди є рядком (string). Використовуйте parseInt(значення, 10) для перевірки віку на >= 18.
  • В атрибут disabled можна передати логічний вираз з операторами ! та ||.

3

Список справ (Рендеринг списків та Key)

Мета: Навчитися рендерити масиви даних, додавати нові елементи та безпечно сортувати/змінювати масив у стані React.

Кроки виконання:

  1. Створіть поза компонентом початковий масив об'єктів initialTodos (кожен об'єкт має мати id, text та priority: 'high' | 'low').
  2. Помістіть цей масив у стан (state) компонента.
  3. За допомогою методу .map() виведіть кожен об'єкт масиву у вигляді тегу <li>.
  4. Додайте форму (input + кнопка) для створення нового завдання. При натисканні створюйте новий об'єкт, генеруйте унікальний id і додавайте його до стану.
  5. Реалізуйте 3 кнопки керування списком: "Сортувати за пріоритетом", "Перевернути список", "Скинути (повернути initialTodos)".
  6. Задайте динамічні CSS-класи для елементів списку залежно від їхнього пріоритету (класи high та low є у стартовому CSS).

💡 Підказки:

  • Найголовніше правило: кожен елемент, який повертає map, ПОВИНЕН мати унікальний атрибут key (використовуйте todo.id).
  • Для генерації унікального ID нового завдання зручно використовувати Date.now().
  • Ніколи не мутуйте масив напряму! Методи .sort() та .reverse() змінюють оригінальний масив. Робіть копію перед зміною: const copy = [...todos].sort(...), а потім передавайте копію в setTodos.

👀 Очікуваний результат списку

  • Вивчити React (High)
  • Вигуляти собаку (Low)
  • Зробити ДЗ (High)
4

Фільтр товарів (Списки + Умови)

Мета: Об'єднати знання про масиви та умовний рендеринг. Навчитися фільтрувати дані перед рендерингом та умовно застосовувати стилі.

Кроки виконання:

  1. Створіть масив товарів (поля: id, name, price, inStock (true/false)) та помістіть його в стан.
  2. Створіть boolean-стан showOnlyInStock (показувати лише ті, що в наявності).
  3. Створіть кнопку для перемикання цього стану. Текст кнопки має змінюватись динамічно: якщо стан true — текст "Показати все", якщо false — "Показати тільки в наявності".
  4. Перед ретурном (return) JSX напишіть логіку, яка створює новий масив filteredProducts. Якщо фільтр увімкнено, відфільтруйте масив, якщо ні — залиште повний. Рендеріть (через .map()) саме цей відфільтрований масив.
  5. Під час рендеру списку, якщо товару немає в наявності (inStock === false):
    • Зробіть текст сірим і перекресленим (використайте інлайн-стилі style={{...}} та тернарний оператор).
    • Додайте поруч із назвою текст (Немає в наявності), використовуючи логічне &&.

💡 Підказки:

  • Тернарний оператор ідеально підходить для тексту кнопки: {умова ? 'Текст1' : 'Текст2'}.
  • Для інлайн-стилів в React використовуються об'єкти: style={{ color: умова ? 'red' : 'black' }}.
  • Метод .filter() не змінює оригінальний масив, а повертає новий. Тому його безпечно використовувати безпосередньо перед return.
