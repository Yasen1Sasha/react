Урок: Хук useEffect

Реагуємо на зміни: завантаження даних, оновлення сторінки, запуск анімації

useEffect — це хук, який дозволяє виконувати побічні ефекти в функціональних компонентах (дії, що не пов'язані напряму з рендерингом UI).

  • Оновлення заголовка сторінки (document.title).
  • Підписка на події (слухачі подій вікна).
  • Запуск таймерів, анімацій або завантаження даних (fetch).
useEffect(() => {
  // Код, який виконується після рендеру
  console.log('Компонент змонтовано або оновлено!');

  // Функція очищення (опціонально)
  return () => {
    console.log('Компонент розмонтовано або перед оновленням');
  };
}, [/* масив залежностей */]);

Приклад 1: Зміна заголовка

Ефект змінює заголовок сторінки щоразу, коли змінюється count.

useEffect(() => {
  document.title = `Ви клацнули ${count} разів`;
}, [count]); // Залежить від count

Приклад 2: Таймер

Функція очищення clearInterval запобігає витокам пам'яті.

useEffect(() => {
  const timer = setInterval(() => {
    setCount(prev => prev + 1);
  }, 1000);
  return () => clearInterval(timer);
}, []); // Виконається один раз

Приклад 3: Робота з API (Fetch)

Завантаження даних та скасування запиту при розмонтуванні.

useEffect(() => {
  const controller = new AbortController();
  const fetchData = async () => {
    const res = await fetch(url, { signal: controller.signal });
    // обробка даних...
  };
  fetchData();
  return () => controller.abort();
}, []);

Приклад 4: LocalStorage

Синхронізація стану React з пам'яттю браузера.

useEffect(() => {
  localStorage.setItem('theme', isDarkMode ? 'dark' : 'light');
}, [isDarkMode]);

Практичні завдання

Завдання 1: Розширений таймер з контролем

Базовий

Чому це важливо: Керування інтервалами на основі стану — це базовий патерн. Якщо таймер не очищати, він продовжить працювати у фоні, викликаючи витоки пам'яті (memory leaks) та непередбачувану поведінку додатку.

Покрокова інструкція:

  1. Створіть файл TimerControl.jsx.
  2. Використайте базовий код, наведений нижче. Вам потрібно написати логіку всередині useEffect.
  3. Налаштуйте setInterval, який збільшує стейт count на 1 кожну секунду, але тільки якщо стейт isRunning дорівнює true.
  4. Поверніть функцію очищення (cleanup function), яка викликає clearInterval.
  5. Додайте масив залежностей до useEffect так, щоб він реагував на зміну isRunning.
💡 Підказка: У функції очищення перевіряйте, чи створено таймер, перед тим як викликати clearInterval(timer).

Вихідний код компонента:

import { useState, useEffect } from 'react';

export default function TimerControl() {
  const [count, setCount] = useState(0);
  const [isRunning, setIsRunning] = useState(false);

  useEffect(() => {
    // ✍️ НАПИШІТЬ ВАШ КОД ТУТ
    // 1. Перевірте, чи isRunning === true
    // 2. Якщо так, створіть setInterval
    // 3. Поверніть функцію для clearInterval
  }, [/* вкажіть залежність */]);

  return (
    <div>
      <h2>Лічильник: {count}</h2>
      <button onClick={() => setIsRunning(!isRunning)}>
        {isRunning ? 'Зупинити' : 'Запустити'}
      </button>
      <button onClick={() => setCount(0)}>Скинути</button>
    </div>
  );
}

👀 Візуальний результат:

На екрані відображається число (лічильник) та дві кнопки. При натисканні на "Запустити" число починає зростати кожну секунду. Напис на кнопці змінюється на "Зупинити". При натисканні на "Зупинити" відлік припиняється. Кнопка "Скинути" обнуляє лічильник.

Завдання 2: Зміна стилів на основі стану

Середній

Чому це важливо: React керує елементами всередині свого кореневого вузла. Щоб вплинути на елементи поза ним (наприклад, тег <body>), ми використовуємо useEffect як безпечний спосіб взаємодії зі звичайним DOM API браузера.

Покрокова інструкція:

  1. Створіть компонент ThemeToggle.jsx.
  2. Усередині useEffect перевірте поточне значення стану theme.
  3. Якщо theme === 'dark', додайте до document.body.classList клас 'body-dark' (він вже є у вашому index.css). Якщо тема світла — видаліть цей клас.
  4. Обов'язково додайте функцію очищення, яка видаляє клас 'body-dark' при розмонтуванні компонента.
💡 Підказка: В масив залежностей обов'язково треба передати стан [theme], щоб ефект спрацьовував тільки при його зміні, а не при кожному рендері.

Вихідний код компонента:

import { useState, useEffect } from 'react';

export default function ThemeToggle() {
  const [theme, setTheme] = useState('light');

  useEffect(() => {
    // ✍️ НАПИШІТЬ ВАШ КОД ТУТ
    // 1. Умова if (theme === 'dark') { ...classList.add... } else { ... }
    // 2. Функція очищення return () => { ...classList.remove... }
  }, [theme]);

  const toggleTheme = () => {
    setTheme(prev => (prev === 'light' ? 'dark' : 'light'));
  };

  return (
    <div>
      <h2>Поточна тема: {theme}</h2>
      <button onClick={toggleTheme}>Перемкнути тему</button>
    </div>
  );
}

👀 Візуальний результат:

При кліку на кнопку весь фон сторінки браузера (а не лише область React-компонента) стає чорним, а текст білим. При повторному кліку стилі повертаються до стандартних світлих.

Завдання 3: Логер подій вікна

Базовий

Чому це важливо: Підписка на події глобального об'єкта window вимагає точного розуміння, коли ефект створюється, а коли знищується. Якщо забути відписатися (removeEventListener), при кожному оновленні компонента створюватиметься новий слухач, що швидко "покладе" продуктивність браузера.

Покрокова інструкція:

  1. Створіть компонент WindowResize.jsx.
  2. Усередині useEffect створіть функцію handleResize, яка оновлює стан width значенням window.innerWidth.
  3. Додайте цю функцію як слухача до події вікна: window.addEventListener('resize', handleResize).
  4. Обов'язково відпишіться від події у функції очищення.
💡 Підказка: Оскільки ми хочемо повісити слухач лише один раз при монтуванні компонента, масив залежностей має бути порожнім [].

Вихідний код компонента:

import { useState, useEffect } from 'react';

export default function WindowResize() {
  const [width, setWidth] = useState(window.innerWidth);

  useEffect(() => {
    // ✍️ НАПИШІТЬ ВАШ КОД ТУТ
    // 1. const handleResize = () => setWidth(...)
    // 2. window.addEventListener(...)
    // 3. return () => window.removeEventListener(...)
  }, []);

  return (
    <div>
      <h2>Поточна ширина вікна: {width}px</h2>
    </div>
  );
}

👀 Візуальний результат:

На сторінці відображається текст із поточною шириною вікна у пікселях. Якщо ви зміните розмір вікна браузера вручну, цифра миттєво оновлюватиметься.

Додаткове завдання: ColorFader (Анімація)

Складний

Чому це важливо: Це завдання інтегрує роботу з масивами, хуком useState, керованими інтервалами та CSS-переходами (transitions). Це реальний патерн для створення слайдерів, каруселей або плавних фонових анімацій.

Покрокова інструкція:

  1. Створіть компонент ColorFader.jsx.
  2. Вам знадобиться два стани: isRunning (булевий, за замовчуванням true) та colorIndex (число, починаємо з 0).
  3. Винесіть константу const COLORS = ['red', 'blue'] ЗА МЕЖІ компонента (щоб не перестворювати масив на кожен рендер).
  4. Усередині useEffect перевіряйте if (!isRunning) return;. Якщо анімація запущена, створюйте інтервал, який кожні 2 секунди збільшує colorIndex.
  5. Для стилізації блоку з кольором використайте inline-стиль style={{ backgroundColor: COLORS[colorIndex] }} і додайте CSS-клас з transition: background-color 1s ease.
💡 Підказка: Щоб індекс не вийшов за межі масиву, використовуйте оператор остачі від ділення (modulo):
setColorIndex(prev => (prev + 1) % COLORS.length)

Вихідний CSS (можна додати у App.css):

.color-box {
  width: 200px;
  height: 200px;
  transition: background-color 1s ease;
  display: flex;
  align-items: center;
  justify-content: center;
  color: white;
  font-weight: bold;
  border-radius: 12px;
  margin: 20px auto;
}

👀 Візуальний результат:

Великий квадрат по центру екрана, який кожні 2 секунди плавно (з переходом в 1 секунду) змінює колір з червоного на синій і навпаки. Під ним кнопка, яка дозволяє зупинити цей процес (заморозити поточний колір) і відновити його.
